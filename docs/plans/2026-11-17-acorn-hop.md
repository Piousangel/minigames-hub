# Acorn Hop (웹 허브 신작) — SPEC

## 목표
- 첫 10초 안에 이해되는 **한 손가락 오리지널 게임**. "쏘면 반대로 튀어 오른다"(Recoil의 규칙)를 조준 없이 탭 하나로.
- 토스 허브 이전 전에 웹에서 **수요를 숫자로 확인**한다(첫 판 완료율, 재방문, 리더보드).
- 오너 지시: 캐릭터(토리)와 배경·오브젝트·UI가 **한 톤(우주 도토리 숲)**이어야 한다. Gemini로 에셋을 만들고 혹평 리뷰 6점 이상에서 출시.

## 규칙
- 화면 왼쪽/오른쪽 절반을 탭하면 토리가 **반대쪽 아래로 도토리를 쏘고 그 반동으로 위로, 탭한 쪽으로 튀어 오른다.** 탄(도토리 주머니)은 유한.
- 중력이 계속 당긴다. 아래로 화면 밖에 떨어지면 끝. 위로 올라간 높이(m)가 점수의 주축.
- 별은 +점수, 도토리는 탄 +3, **쉼터 섬**에 내려앉으면 탄이 기본치까지 채워진다(쉼터는 약 700px마다).
- 가시덤불(고정)·심술 구름(좌우로 흐름)에 닿으면 끝. 위로 갈수록 위험물이 늘어난다.
- Daily(모두 같은 판, UTC 기준)와 Practice(매번 새 판).

## 하지 않을 것 (v1)
- 도전 링크·공유 카드·연속 기록·리더보드(웹 허브 리더보드 화이트리스트 작업 필요, v2).
- 캐릭터 해금(토스 허브용 시스템은 toss/ 브랜치에 있음). v1은 토리 단독.

## 완료 조건
1. 순수 엔진(`src/lib/games/acornhop/engine.ts`) + 단위 테스트: 같은 시드·입력이면 같은 결과, 탄 소진, 쉼터 착지, 위험물 충돌, 낙하 종료.
2. 레지스트리 등록(SEO 본문·FAQ·howToPlay), gameMeta, 아이콘, e2e 스모크.
3. 타입 검사·린트·전체 테스트·빌드 통과.
4. 모바일 폭(390) 캡처 + Gemini 혹평 리뷰 **6점 이상**(미만이면 수정 후 재평가).
5. 수정 사항은 PR 한 개, 머지는 CI 초록불 후.

## 구조 스케치
- `engine.ts`: `createGame(seed)`, `step(state, input)`, `objectsInRange(seed, y0, y1)`, 상수. DOM·Date·Math.random 없음.
- `GameAcornHop.tsx`: canvas + rAF 고정 60Hz 틱, 입력 큐, 스프라이트 로드(`/art/*.webp`), 결과 오버레이, 기록(recordFinish), best 저장.

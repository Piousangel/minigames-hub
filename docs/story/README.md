# docs/story — 해바라기 군도 이야기

퀵미니게임즈의 네 친구(말랑이·토리·해씨·보미)와 '노을 정원' 세계의 이야기를 모으는 곳이다. 오너 요청(11-20): "4친구 및 우리 전체적인 이미지 등을 고려해 스토리 같은 것도 만들자. 꾸준히 만들다 보면 언젠간 쓰일지도."
사이트는 영어 전용이라 모든 글은 **한국어 원문 + 영어 판**으로 쓴다. 지금은 문서일 뿐 사이트에 들어가 있지 않다.

## 먼저 읽을 것 (이 폴더보다 위에 있는 규칙)
1. [월드 바이블](../design/world/world-bible.md) — 섬 이름, 생김새, 색, 금지 목록. 그림과 장소는 여기가 정답.
2. [리디자인 v2 계획서](../plans/2026-11-19-hub-redesign-v2.md) D5·D6 — 마스코트 ↔ 카테고리 1:1, 한 화면에 한 마리.
3. 그림: `public/art/mallang-*`, `tori-*`, `haessi-*`, `bomi-*`, `docs/design/mascots/haessi-sheet.webp`, `bomi-sheet-v2.webp`.
4. 게임을 이야기에 넣을 때: `src/lib/games/gameIntros.ts`의 그 게임 설명(규칙을 실제와 다르게 쓰지 않는다).

## 새 편을 쓰는 방법
1. 번호는 마지막 편 + 1. 파일 이름은 `episodes/NNN-<영어 제목 슬러그>.md`.
2. 머리말(정사·등장·장소·연결 게임·새로 정한 사실)을 STORY-BIBLE 5-1 형식으로 채운다. 처음엔 `정사: draft`.
3. 한국어를 먼저 쓰고, 영어는 **다시 쓴다**(직역 금지, 짧은 문장·소리 나는 말·반복 리듬).
4. 끝에 '사이트에 쓸 수 있는 한 줄' 3개(한·영, 어느 자리용인지 괄호로).
5. STORY-BIBLE 5-2 연속성 체크리스트 10항목을 확인하고, 새 설정은 5-3 사실 장부에 한 줄 추가.
6. 독립 리뷰(작성자 ≠ 검토자, 아동 그림책 편집자 + 브랜드 관점)를 받고 반영한 뒤 `정사: canon`으로 바꿔 PR. PR 범위는 `docs/story/`만.
7. 쓸 만한 새 한 줄은 lines.md에도 옮긴다(태그·자리·길이 한도 지키기).

## 이야기 소재가 떨어지면
- 게임 하나 + 친구 둘 + 작은 문제 하나(바람, 빈 주머니, 길 잃음, 늦잠) + 몸으로 푸는 해결.
- 사이트에 새 기능이 생기면 그 기능을 설명하는 짧은 '왜' 이야기(예: 리더보드 → 별우물에서 별이 솟는 날).
- 계절 소품(월드 바이블 4장 날씨·9장 계절 이벤트): 꽃잎 날림, 반딧불, 도토리 풍년, 함박눈.

# 바로 쓸 수 있는 짧은 대사 40줄

규칙은 [STORY-BIBLE.md](./STORY-BIBLE.md) 3장(톤)·4장(자리별 길이)을 따른다.
- 태그: `[말랑]` `[토리]` `[해씨]` `[보미]` `[서술]`(마스코트 그림이 없는 자리에 쓰는 내레이터 문장).
- 말랑이는 말을 하지 않는다. 그래서 `[말랑]` 줄은 모두 3인칭 서술이다.
- `{time}`·`{n}` 같은 자리는 사이트가 채운다. 숫자를 문장에 박지 않는다.
- **D6**: 화면에 그림이 있는 마스코트의 줄만 쓴다.
  - 지금 결과 시트와 카운트다운 자리의 그림은 보미뿐이다(R6). 그래서 그 섹션에는 보미와 서술 줄만 둔다.
  - 말랑·토리·해씨의 결과 반응은 맨 아래 '게임별 반응(예비)'에 따로 모았다. 게임별 마스코트 반응 부품이 생기기 전에는 쓰지 않는다.
- 보미는 손님에게 존댓말을 쓴다(바이블 2-4). 친구끼리 하는 반말은 단편에서만 쓴다.
- 영어 길이 한도(공백 포함)
  - 결과 ≤ 60자
  - 카운트다운 ≤ 40자(시간 자리 제외)
  - 로딩 ≤ 32자
  - 404 본문 ≤ 120자
  - 빈 상태 ≤ 90자
  - 공유 ≤ 50자

## 넣을 때 확인할 것
- 공유 문구 구조는 DECISIONS 11-20 R5를 따른다. 사이트가 "게임 원래 결과 문구 + Today's garden n/3 · No. N"을 만든다. 30~32는 그 앞에 붙이는 선택 문장이다. 이름이나 기기 정보는 넣지 않는다.
- 5번은 오늘의 정원이 3/3일 때만 쓴다.
- 8번과 11번은 뿅 착지 전용이다. 8번은 바람이 부는 섬(다섯 번째부터)에서 놓쳤을 때, 11번은 Perfect일 때만 쓴다.
- 10번은 리더보드에 실제로 오른 판에만 쓴다. 12번은 이 기기의 최고 기록을 넘었을 때만 쓴다.
- 13번처럼 '거의'로 끝나는 농담은 한 화면에 한 번만 쓴다.
- 17번의 '심어 둘게요'는 즐겨찾기를 정원의 비유로 말한 것이다. 표지판에 글자를 적는다는 뜻이 아니다.

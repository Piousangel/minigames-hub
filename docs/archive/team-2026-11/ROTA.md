## 교대 규칙 (모든 팀)
0. **북극성(허브·샌드랩)**: 시작할 때 자기 저장소 `docs/team/NORTH-STAR.md`를 보고, 이번 교대 일이 4장 어느 단계·2장 어느 지표를 움직이는지 HANDOFF(샌드랩은 `.claude/handoff/main.md`) 첫 줄에 쓴다(못 대면 우선순위를 다시 고른다). 끝날 때 HANDOFF·cycle에 **지표 한 줄**: `북극성 <오늘 값 또는 '측정 없음'> · 이번 교대가 움직인 지표 <이름>`.
1. 시작: `git pull`, `gh pr list`·`git branch -r`로 진행 중 작업 확인 — 같은 파일·같은 PR 항목을 겹쳐 하지 않는다(이어받기는 OK).
2. 브랜치 `shift/<시각>-<주제>`(더런은 기존 `daily/` 규칙), PR은 작게(M 이하). 머지 전 전체 테스트·타입체크·(엔진은 골든 비트 동일). main CI가 빨강이면 그것부터.
3. 병렬로 나눌 일은 서브에이전트(worktree 격리)로 역할별(기획·디자인·엔진·QA) 분담하고, 결과는 한 PR로 모은다.
4. 종료: HANDOFF.md·cycle.md에 한 일/막힌 것/다음 교대가 이어서 할 것을 같은 PR에 남긴다.
5. 금지(공통): main 직접 푸시, force push, 테스트 약화·삭제, 시크릿 노출, 광고를 게임 화면에, AdSense 재심사 신청, 공유 URL·slug 변경, 오너 보류 항목의 외부 게시(말랑 홍보는 오너 해제 전까지 금지), 보고 주소 외 메일.
6. 한도: 공유 사용량 한도에 걸리면 세션이 5초 만에 끝나므로, 교대 시작 즉시 작업이 거절되면 handoff에 "한도 거절"을 적고 종료한다(다음 교대가 이어받음).

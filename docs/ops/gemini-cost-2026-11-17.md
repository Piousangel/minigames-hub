# Gemini API 비용 분석 (2026-11-17)

환율 가정: $1 = ₩1,450 (추정, 실제 청구 환율과 다를 수 있음). 가격은 USD 표준(Standard) 기준.
확인 등급: **요약 확인** = WebFetch/검색 요약으로만 본 것(원문 전체는 직접 못 봄), **추정** = 근거 숫자 없이 계산한 것.

## 0. 한 줄 결론
- 월 구독(Google AI Pro/Ultra)은 **API 호출 한도를 주지 않는다.** 구독 혜택은 AI Studio 웹 화면에만 적용된다. 구독에 딸린 월 Cloud 크레딧(Pro $10 정도)이 있지만 별도 절차가 필요하고 금액은 출처마다 다르다.
- 현재 상한(월 150장)이면 월 비용은 **약 ₩12,000~27,000**으로 묶인다. 하루 1출시를 다 하려면 월 비용이 **₩34,000~139,000**이고, 150장으로는 모자란다.
- 권장: 월 예산 **₩40,000**, 상한은 **250으로 조건부 상향**(절감안 적용 전제).

## 2. 현재 API 요금표 (https://aistudio.google.com/docs/pricing, WebFetch 요약 확인)
### 이미지 모델 (장당)
| 모델 | 0.5K | 1K | 2K | 4K | 장당 원화(1K) |
|---|---|---|---|---|---|
| gemini-3-pro-image (최종) | - | $0.134 | $0.134 | $0.24 | 약 ₩194 |
| gemini-3.1-flash-image (초안) | $0.045 | $0.067 | $0.101 | $0.151 | 약 ₩97 (0.5K 약 ₩65) |

- 출력 토큰 단가: pro-image 이미지 $120/1M, flash-image $60/1M. 입력(참조 이미지·프롬프트)은 pro $2.00/1M, flash $0.50/1M. 참조 이미지 1장의 토큰 수는 **확인 못 함**. pro-image는 이미지 1장 입력이 약 $0.0011이라고 표기됨.
- pro-image는 1K와 2K가 같은 가격이다. 쓸 거면 2K로 뽑아도 비용이 같다. (우리는 어차피 `size`로 줄여 webp로 저장)
- **Batch: 두 이미지 모델 모두 Batch 가격 없음**(Batch 탭 없음). 컨텍스트 캐싱도 이미지 모델에는 표기 없음.

### 텍스트 모델: gemini-3.1-pro-preview (혹평 리뷰)
| | Standard | Batch |
|---|---|---|
| 입력 ≤200k | $2.00/1M | $1.00/1M |
| 출력(생각 포함) ≤200k | $12.00/1M | $6.00/1M |
| 캐싱 읽기 ≤200k | $0.20/1M | Standard와 동일 |
| 캐싱 저장 | $4.50/1M 토큰/시간 | 동일 |

Batch는 50% 할인이다. 단 혹평 리뷰는 다음 PR을 막는 경로가 아니므로 Batch로 돌려도 되는지가 쟁점이다. 현재 스크립트는 동기 `generateContent`만 쓴다. 혹평 1회 비용은 입력 약 2k·출력 약 3k토큰(생각 포함)으로 가정하면 약 $0.04(약 ₩58, **추정**)라서 절감 효과가 작다. 캐싱·Batch는 혹평에는 실익이 거의 없다.

- 현재 잔액 ₩10,835는 보통 단가로 약 5사이클(약 5일)분이다. 11-16 충전 ₩28,000을 포함해도 오늘 이후 하루 1출시면 약 2주를 못 버틴다(보통 기준).

### 예산 알림·상한 설정
- AI Studio 쪽: 선불(prepay) 방식에서 자동 충전은 **꺼진 채**가 맞다. 이것이 사실상의 하드 상한이다(잔액 0이면 키 중단, 청구 지연 약 10분 때문에 소폭 초과 가능). Spend 페이지의 프로젝트 지출 상한은 experimental이라 보조 수단으로만 쓴다.
- Cloud Billing 쪽: 결제 계정에 **예산(Budget)과 임계 알림(50/90/100%)** 을 만들 수 있다. 이 문서에서는 이 기능을 직접 확인하지 못했다(**추정**, AI Studio 결제 계정이 Cloud Billing 계정에 연결된다는 점은 위 billing 문서에서 확인). 알림만 오고 차단하지는 않는다.
- 코드 쪽: `MAX_PER_MONTH`, `MAX_PER_RUN`을 환경변수로 이미 막고 있다. 가장 확실한 상한이다. 비용 기준 상한(누적 USD)을 장부에 넣는 개선을 권한다(장부에 단가×수량 기록).

## 5. 다른 구독·대안
- **Gemini 앱(구독)에서 수동으로 뽑아 저장소에 넣기**: 비용은 0에 가깝지만 자동화가 불가능하다. 우리 흐름(요청 JSON → Actions → main 커밋)이 끊기고, 사람이 매일 5회 세션마다 손으로 해야 한다. 브라우저 자동 조작으로 우회하는 것은 약관상 비권장이라 **하지 않는다**(약관 원문은 직접 확인 못 함, 일반적 권고). 구독 한도·모델 접근은 요금제별로 달라 보장이 없다. 현실성은 "오너가 가끔 대표 컷 1~2장을 손으로 넣는 보조 용도"까지만.
- **AI Studio 웹 화면**: Pro/Ultra의 높은 AI Studio 한도는 웹에서 손으로 쓸 때만 해당. 같은 이유로 자동화에는 쓸 수 없다.
- **다른 이미지 API**: 이번 조사 범위에서는 가격을 확인하지 않았다(**확인 못 함**). flash-image 1K가 장당 약 ₩97이라 대체 이득이 크지 않을 것으로 보이며, 스타일 일관성 때문에 모델을 섞는 비용이 더 크다. 현 단계 비추천.
- **Pro 구독 월 Cloud 크레딧**: Pro 월 구독료 대비 크레딧 $10(약 ₩14,500, 추정)은 우리 보통 월 비용 일부만 덮는다. 오너가 이미 개인 용도로 Pro를 쓰고 있다면 활성화해서 공짜 크레딧으로 쓰는 것은 의미가 있다. 이 목적만으로 구독하는 것은 비추천. 활성화에는 Cloud 결제 계정 연결과 AI Studio 유료 잔액 > 0이 필요(요약 확인).

## 6. 결론
- **월 예산 권장: ₩40,000.** 근거: 절감안 적용 후 보통 시나리오 월 약 ₩30,000~38,000에 소폭 여유를 둔 값이다. 절감안 미적용으로 매일 출시하면 보통도 약 ₩61,000이라 초과한다.
- **충전 시점 규칙:** 잔액 **₩5,000 미만이면 ₩20,000 충전**(최소 $5 이상). 1일 보통 사용 약 ₩2,000 기준 잔액 ₩5,000은 약 2일치 안전선이다. 청구 지연(10분)과 하루 세션 5회를 고려해 ₩3,000까지 내려가면 멈추는 쪽이 낫다. 자동 충전은 계속 꺼 둔다(폭주 방지). 대신 충전 기준일을 매주 월요일 점검으로 둔다.
- **상한 상향 의견:** 150은 하루 1출시에 너무 작다. **250으로 조건부 상향**(에셋 재사용·재생성 금지 적용 후), 효과가 확인되면 재검토. 상한 250의 최대 지출은 보통 단가 약 ₩21,000, 비관 단가 약 ₩45,000이다. 실행당 12 상한은 유지(폭주 방지).
- **오너가 결정할 것:**
  1. 월 예산을 ₩40,000으로 할지, 그리고 `MAX_PER_MONTH`를 150→250으로 올릴지.
  2. 하루 1출시를 유지할지, 신작은 격일로 하고 사이클당 에셋을 재사용 위주(3~5장)로 줄일지.
  3. 개인 Pro 구독이 있다면 Developer Program 월 크레딧($10 추정)을 활성화해 API 비용에 보탤지, 그리고 정기 충전 담당·시점(잔액 ₩5,000 미만 ₩20,000).

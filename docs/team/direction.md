# 팀 방향 (살아있는 문서)

아침 팀이 매일 갱신한다. 틀린 줄은 지우고, 쌓아두기만 하지 않는다. 작성 규칙은 [OPERATING.md](./OPERATING.md) 4장.

## 현재 방향 (3줄)
1. AdSense 승인: 게임마다 고유한 공략·해설 콘텐츠(시뮬레이션·엔진 근거)를 늘린다.
2. 재방문: 데일리·스트릭·리더보드를 사람이 실제로 쓰게 만든다. 지금은 기능만 있고 참여가 거의 없다.
3. 첫 화면: 지금은 슬로건만 보이고 게임이 안 보인다. 방문 직후 바로 한 판으로 이어지게 만든다.

## 부족한 점 (확인된 것)
- **리더보드 참여 0** (11-13 확인).
  - 기능은 정상이다. 실사이트 2048에서 플레이 → 제출 → 보드와 /leaderboards 반영까지 확인했다.
  - 하지만 역대 점수가 2건뿐이라 이번 주 83개 보드가 전부 "No scores yet"이고, 방문자에게는 고장처럼 보인다.
  - 원인: 제출 폼이 페이지 하단에만 있다. 게임오버 오버레이에는 스크롤 링크만 있다.
- **외부 유입 경로가 약하다.** 11-11 이후 마케팅 게시가 없었고 11-13부터 Actions 게시를 시작한다.
- **측정 공백.**
  - D1 지표(점수·댓글)는 토큰 권한이 없어 수집되지 않는다.
  - 홈 인기순 레일은 Worker 시크릿 `CF_ANALYTICS_TOKEN`이 비어 있어 큐레이션 순서로만 나온다.

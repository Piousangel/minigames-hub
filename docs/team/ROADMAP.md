# 성장 로드맵: 더 좋은 게임 → 후원 → 서버·DB → 결제 (오너 지시 2026-11-17)

목표: 계속 더 높은 퀄리티의 오리지널 게임을 내고, 그 위에 서버·DB, 나중에 결제를 단계적으로 붙인다. 각 단계는 **앞 단계가 숫자로 검증됐을 때만** 연다.

## 단계
| 단계 | 내용 | 열리는 조건(숫자) |
|---|---|---|
| 0. 지금 | AdSense(심사 중), Ko-fi 후원, 게임 품질 | - |
| 1. 퀄리티 반복 | 주 1회 이상 신작 또는 큰 개선(11-20부터 신작 공개는 오너 승인 B 관문 통과 뒤만 — [NORTH-STAR](NORTH-STAR.md), 90일 신작 공개 목표 1개). 신작은 Gemini 목표 시안 → 에셋 → 혹평 리뷰 6.5점 이상 → 출시 | 신작마다 회고에 완주율·재방문 기록 |
| 2. 서버·DB (계정 없는 익명 ID부터) | 리더보드 확대, 친구 도전, 연속 기록 서버 저장. Cloudflare D1/Workers 사용(이미 리더보드 운영 중). 로그인은 나중, 먼저 익명 기기 ID | 한 게임의 주간 활성 플레이어 ≥ 300 또는 리더보드 제출 주 50건 이상 |
| 3. 계정과 저장 | 소셜 로그인(Google 등), 기기 간 진행도 동기화 | 재방문(D7) ≥ 15% |
| 4. 결제 | **꾸미기 전용**(캐릭터 스킨, 테마)과 후원. 경쟁·랭킹에 영향 주는 판매 금지(pay-to-win 금지) | 계정 가입자 ≥ 1,000, 꾸미기 수요 신호(해금 화면 클릭률) |

## 결제 사전 준비물 (오너 전용, 단계 4 전에)
- 사업자: 개인사업자 "행복가게" 보유(게임 소프트웨어 업종 722001·722002 추가 신청함, 홈택스 처리 확인).
- 디지털 상품 판매 시 **통신판매업 신고**와 PG(결제대행) 가입 필요. 해외 결제는 Stripe 등을 쓸 수 있으나 정산·세무는 오너 확인.
- 토스 앱인토스는 별도 경로(앱 단위 등급분류·정산, docs/team/toss-hub/PLAN.md).
- 어떤 경우든 **결제 전에 환불·개인정보 처리방침과 이용약관** 갱신, 미성년자 대응 확인.

## 다음 신작 계획 (두 팀 공통 규칙)
- **같은 형식을 연속으로 만들지 않는다**(GROWTH.md). Acorn Hop(탭형 클라이머) 다음은 다른 입력·다른 리듬의 게임으로 간다.
- **후보와 설계는 회의에서 바로 시작한다**(요일을 기다리지 않는다). 신작은 H2 카드(B 관문 전 비공개, [SHIFT.md](./SHIFT.md) 3장). 확정 순서: **① A 「뿅 착지」 → ② B 「말랑 미끄럼길」**(docs/team/next-game-candidates-2026-11-17.md).
- 제작 순서: 목표 시안(Gemini) → 에셋 요청 PR → 구현 → 모바일 캡처 → 혹평 리뷰 6.5점 이상 → 커버(16:9) 추가 → 출시 → **한 주 뒤 숫자로 판정**.
- 출시 후 홈 상단 '최신 출시' 카드에 자동 노출된다(cover 필수).

## 지표 기준(회고에서 매주 적는다)
게임별 완주(finish) 수, 첫 판 이탈률, 재방문(D1·D7), 판당 시간, 리더보드 제출 수, 공유·도전 링크 전환.

## 사이트 성장 축 (오너 지시 11-17: AdSense·결제까지 쭉쭉)
숫자 조건은 **기능을 켜는 시점**만 막는다. 준비는 지금 한다: 익명 ID·D1 스키마 설계, 개인정보 처리방침·이용약관·환불 정책 초안, 결제 전 체크리스트, 꾸미기 해금 화면 계측, AdSense 승인 준비(콘텐츠·정책 페이지·사이트 품질). 주 1회 수요일 회의에서 현재 단계와 이번 주 사이트 작업 1개를 정한다.

**404**: "This path leads off the island." 구름 끝에 매달린 말랑이(dizzy). 버튼 [Back to the garden] [🎲 Toss a seed]. 랜덤 게임 3개. 광고 없음.

**시그니처 인터랙션 3**
1. **Living Sky(살아 있는 하늘)**: 방문자 현지 시각으로 헤더 아래 하늘 그라데이션과 해·달 위치가 바뀐다(새벽 5–8, 낮 8–16, 노을 16–20, 밤 20–5). SSR 기본은 노을이다. 클라이언트에서 CSS 변수만 바꾸므로 hydration 불일치와 CLS가 없다. 움직임 줄이기에서도 색은 바뀌고 움직임만 멈춘다.
2. **Today's Garden(오늘의 정원)**: 어떤 게임이든 한 판 끝내면 헤더 오늘 pill이 늘어나 "+1 🌼"를 보여 주고, 내 섬(홈 히어로)에 꽃이 하나 핀다(localStorage, 이미 있는 RecentlyPlayed·streak 데이터 재사용). 서로 다른 카테고리 4개를 하면 드문 손님(나비)이 온다(Neko Atsume식 수집, 경쟁 아님). 공유 이미지가 이 정원이다.
3. **Jelly Press(젤리 눌림)**: 주 버튼·섬 카드·pill은 누르면 3px 가라앉고 scaleY 0.96, 놓으면 spring(220/12)으로 한 번 오버슈트한다. 커서가 오래 머물면 말랑이가 카드 모서리에서 **빼꼼**(peek)한다(1440 전용, 세션당 3회 상한).
   (보너스) **Toss a seed**: Random 버튼을 누르면 봉투가 흔들리다 씨앗 하나가 튀어 게임 카드로 펼쳐진다(600ms, 스킵 가능).

- 헤더: 크림 `rgba(255,250,240,.86)` + backdrop-blur 8 + 아래 2px ink 선(점선 아님). 로고는 말랑이 기호판 + "Quick MiniGames"(Fraunces 600, SOFT 100). 픽셀 폰트는 사이트에서 은퇴시킨다.

### 안 B. 「Garden Almanac / 정원 연감」 — 매일 발행되는 그림책 신문

**한 줄**: 사이트는 하루 한 호씩 발행되는 정원 연감이다. 첫 화면은 "오늘 호 표지", 게임은 칼럼, 일러스트는 삽화다.

**AdSense**: 젤리 UI 곁의 평평한 광고가 **가장 이질적**이다. 물리 UI가 광고 근처에서 출렁이면 실수 클릭 위험이 있다(정책 위험 최대).

**약점**: 성능 비용이 가장 크다(물리·굴절). 귀엽기만 해서 금방 질린다("우아" 실패 위험). 토리(다람쥐·도토리)는 젤리 소재와 맞지 않아 세계관이 오히려 좁아진다. 모바일 스크롤 중 물리는 오작동이 잦다.

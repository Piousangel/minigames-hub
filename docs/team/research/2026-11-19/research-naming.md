## 3. 상표 DB 접근

- KIPRIS: 메인 페이지에서 상표 검색이 로그인 없이 제공된다고 확인(로그인 필요한 건 서비스 설정뿐) [확인]. 단 동적 검색 결과를 이 도구로 조회하지는 못함 → 접근 가능, 이번 조사에서는 미조회.
- USPTO: tmsearch.uspto.gov 페이지 열림은 확인되나 JS 검색 앱이라 질의 불가 [확인] → 오너 직접 확인.

  - USPTO: https://tmsearch.uspto.gov → "Basic word mark search", 검색어 FENCE GARDEN, PETAL FENCE, GARDEN WALLS, MALLANG, 클래스 9·41·28, 상태 live만 보기.
  - 보조: WIPO Global Brand Database https://branddb.wipo.int , EUIPO https://euipo.europa.eu/eSearch
  - 스토어 확인: App Store·Google Play에서 각 이름 정확 일치 검색, Steam, itch.io, 보드게임긱(boardgamegeek.com)에서 같은 이름 검색.

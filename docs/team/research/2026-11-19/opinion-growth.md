### 1-2. 판정 지표와 규칙 (표본이 작을 때)
**측정 전제(개발 요구)**: localStorage 익명 device_id + first_seen_date. 이벤트: sl_day_start, sl_stage_clear(stage), sl_stage_fail(stage), sl_day_complete, sl_return(day_n), sl_share, lb_submit(sl). (현재 sl_* 이벤트 일부는 있음: sl_view, sl_run, sl_win_s1 등. 어떤 이름이 쓰이는지 확인 필요.)

지표(우선순위):
1. **퍼널**: view → S1 시작 → S1 클리어 → S2 시작 → 일일 완료. 단계별 전환율(분모 명시). 현재 sl_view 2에 sl_win_s1 1이라 퍼널이 사실상 비어 있다.
2. **일일 완료율** = 일일 완료 기기 / 일일 시작 기기.
3. **다음날 복귀율(D1)** = 시작일 다음 날 sl_day_start가 있는 기기 / 시작 기기. 허브 전체가 아니라 **이 게임 기준**.
4. 보조: 일일 스테이지당 평균 시도 수(5회 이상이면 난이도 과다 신호), 공유율, lb_submit율.

판정 규칙(표본 작을 때):
- **N 게이트**: 7일간 S1 시작 기기 < 30이면 **판정 보류**하고 홍보 전에는 판정 시도 자체를 하지 않는다(표본 부족은 실패가 아니다). 홍보 재개 후 14일까지 보류 연장 가능, 그 이상은 "트래픽 부족"으로 별도 결론.
- N ≥ 30이면 **비율은 반드시 구간과 함께** 적는다(Wilson 95%). 예: 완료 12/30 = 40%, 구간 약 25~58%. 구간 하한으로 판단한다.
- 기준(잠정, 첫 측정 후 조정): S1 클리어율 하한 ≥ 60%, 일일 완료율(S1 클리어자 중) 하한 ≥ 30%, D1 하한 ≥ 8%(점추정 15%는 ROADMAP 3단계 기준과 일치시키되, N<100이면 하한 기준을 쓴다).
- **A/B는 하지 않는다.** 하루 수십 명 규모에서는 검정력이 없다. 대신 전후 비교는 "홍보 기여 유입(ref=threads/bluesky)"과 "자연 유입"을 분리해서 본다. 홍보 스파이크 날의 신규 방문은 D1이 낮게 나오므로 스파이크일과 평시를 따로 적는다.
- 질적 보강: 10명 미만이어도 "어느 스테이지에서 처음 3번 연속 실패 후 이탈했는가"는 이벤트 로그로 전수 확인 가능. 숫자가 작을 땐 이게 더 정보가 크다.
- 판정일: 홍보 재개 후 14일. 결과 3종 중 하나로 기록: 확대(일일 구조 유지, 다른 게임에 복제) / 1회 변형(일일 개수·난이도 조정) / 폐기(이유 기록). 판정일에 안 쓰면 실패 처리(GROWTH 3번).

### 1-4. 리더보드 노출: 오늘 합산 vs 단계별
권고: **기본은 "오늘 합산" 하나**. 이유: 표본이 작은 사이트에서 보드가 4개(단계별)로 쪼개지면 각 보드가 "No scores yet"이 된다(허브 현황 지적과 동일). 빈 보드는 경쟁 심리를 오히려 죽인다. 단계별은 **내 기록 vs 오늘 중앙값** 한 줄로만 표시(별도 보드 없음). N ≥ 50/일이 7일 지속되면 단계별 보드 개봉.
- 제출 직후 "#N / M · 상위 P%"(S1 계획과 동일) + 아직 아무도 없으면 "오늘의 첫 기록" 배지(내가 1등이어도 의미 있게).
- 표본이 작을 때 "내 순위 위 1명과의 차이"(예: 위 사람과 잉크 3점 차)가 순위 숫자보다 동기가 크다 [추정].

### 4-1. 노출안
1. **홈 레일 "말랑 하늘섬 시리즈"**: 홈 상단(최신 출시 카드 아래) 가로 레일에 오리지널 3~4종 카드, 각 카드에 "오늘의 일일 상태"(미완료/완료·내 기록) 표시. 첫 화면 개편 실험(11-19) 구조를 건드리지 말고 **그 실험 판정 후**(12-10) 배치한다. 지금은 AdSense 심사 중이라 홈 큰 구조 변경 금지에 걸린다.
2. **다음 게임 추천**: 이미 next_show 8·next_seen 17·next_same 7이 있어 기능이 돌고 있다(?ref=next 12 유입). 규칙: 오리지널을 끝낸 직후 **같은 시리즈의 다른 게임**을 최우선 추천(세계관 캐릭터 이름을 카드에 표기). 측정: next_show→next_click 전환율.
3. **공통 일일 스트릭**: "오늘 하늘섬 3곳 중 1곳 이상 일일 완료 = 불꽃 1". 게임마다 스트릭을 만들지 않고 시리즈 하나. 이유: 한 게임이 안 맞는 날에도 스트릭이 유지돼 이탈이 줄어든다 [가설]. 스트릭은 localStorage, 서버 저장은 S2 이후. **스트릭 끊김 공포로 광고·구매를 유도하지 않는다**(결제 연계 금지 원칙).
4. **합산 주간 랭킹**: 3종 일일 점수를 각각 정규화(오늘 백분위)한 뒤 주간 합. 단, **S2 선행**(일/주 보드, 익명 player_id). 지금 규모(lb_submit 13/주)에서는 보드가 비어 있으므로 "주간 합산"은 N ≥ 50 제출/주가 되기 전에는 만들지 않고, 대신 게임별 "오늘 첫 기록" 배지를 쓴다.

### 4-2. 측정
- **시리즈 교차율** = 오리지널 A를 한 기기 중 같은 주에 B도 시작한 기기 / A 시작 기기. 현재는 기기 ID가 없어 불가 → 개발 선행. 기준: 홈 레일 도입 전 2주를 기준선으로(표본 작으면 절대 수와 구간으로 적음).

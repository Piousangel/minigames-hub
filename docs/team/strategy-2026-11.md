## 1. 신작 파이프라인
- **기준(4개 모두)**: ① 한 줄 고유 재미 "○○인데 △△" ② 30초 안에 규칙 이해 ③ 다시하기 동기(점수·데일리) ④ 공유할 결과(결과 카드/도전 링크).
- **품질 최소선**: 감사 6축 합계 21/30 이상, depth·curve 각 3 이상(현 평균 17.7, depth 2.46·curve 2.61). 미달이면 출시하지 않는다.
- **검증**: 엔진 단위 테스트 + e2e 스모크 + 봇 시뮬로 난이도 곡선(2048·Battleship 공략과 같은 방식).
- **묶음 출시**: 게임 + 데이터 공략 1편 + 공유 카드 + 마케팅 큐(Bluesky 영어·Threads 한국어).
- **주기**: 2주 1개. 나머지 슬롯은 상위 게임 개선·공략. (110종 중 약 60개는 검색 수요 없음 — 양산은 이미 실패.)
- **첫 3개 후보(기획 단계, 검증 전)**: ⓐ 데일리 1회 한정 "한 줄 추리" 퍼즐(매일 1판, 결과 이모지 공유) ⓑ 기존 인기 게임(2048)의 규칙을 비튼 변형 모드(시드 도전 링크 재사용) ⓒ 리듬/타이밍 계열 중 감사 상위(Lagline·FizzBeat)를 확장한 주간 챌린지. 11-18 이후 게임 디자이너가 각 한 장 기획서로 구체화.

## 2. 첫 화면 개편안 (실험 1, 스펙: specs/2026-11-16-home-above-the-fold.md)
순서: ① 한 줄 가치 + **오늘의 데일리 플레이 버튼**(스크롤 없이) ② 인기 게임 카드 6장(썸네일, 클릭 계측) ③ 스포트라이트 ④ 카테고리. 히어로 높이는 현재의 절반 이하. 홈 HTML 334KB → 100KB대로(전체 목록은 카테고리로). 7일 측정, 지표: 카드 클릭률·홈→게임 view 전환. AdSense 심사 중이므로 필수 페이지·푸터는 건드리지 않는다.

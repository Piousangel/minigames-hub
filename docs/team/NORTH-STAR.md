## 3. 하지 않을 것
1. **신작 공개 서두르기·같은 형식 연속.** 신작은 B 관문(8항목 평균 ≥ 2 + 48시간 내부 써 보기) 전에는 내부 프로토만. 13·18시 교대의 신작 프로토(Dusk Sling·Secret Rule 등)도 같다.
2. **게임 화면 안 광고, 심사 중 광고 위치 실험, AdSense 재심사 신청**(신청은 사람이).
3. **slug·공유 URL·점수 체계·저장 키 변경** — 퀄리티 PR에서도(QUALITY.md 4장). R7 배치를 20개보다 크게 묶지 않는다.
4. **측정 없는 홈 실험 연타·숫자 조건 전 서버 기능.** 홈 실험은 한 번에 1개(above-the-fold.md). [ROADMAP](ROADMAP.md) 단계 조건 전에는 켜지 않는다: 익명 ID 서버·DB = 주간 활성 300 또는 제출 주 50, 계정 = D7 ≥ 15%, 결제 = 가입 1,000.
5. **다국어 확장·밤 정원(R8)·홈 '살아 있는 하늘'**: 오너 결정 대기·보류. 이 90일은 영어 단일 + 노을 고정.

## 5. 결정 원칙 (오너에게 묻기 전에)
1. **신뢰 > 속도.** 오답을 떨어뜨리는 검사가 통과하지 않으면 머지하지 않는다.
2. **되돌릴 수 없는 것만 무겁게.** slug·URL·광고 위치·서버 저장 형식은 `고위험`(리뷰 2회), 애매하면 오너에게. 나머지는 팀이 정하고 DECISIONS에 남긴다.
3. **북극성에 가까운 일 먼저.** 재방문 길(오늘 호 진입 → 완료 → 내일)을 짧게 하는 일 > 기존 게임 깊이 > 유입(SEO·공유) > 새 게임 > 장식.
4. **깊이 > 개수.** 한 게임을 2점에서 3점으로 올리는 것이 114번째 게임보다 낫다.
5. **숫자로 판정, 없으면 측정부터.** 출시 14일 창으로 판정한다. n < 30이면 숫자 대신 검사·재현·플레이 테스트 증거로 판정하고 "표본 부족"이라 적는다.

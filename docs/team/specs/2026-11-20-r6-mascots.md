### 2-3. D6 해석 (v1 팀 결정 — 리서치 2에서 반증 시도)
- D6 '한 뷰포트 1마리'는 **전신 일러스트(≥56px)** 에 적용한다. 40px 이하 원형 얼굴 배지는 카테고리 아이콘(내비 요소)으로 본다 — 근거: 포털·앱의 카테고리 아이콘 관행, 4마리↔4카테고리(D5)를 사용자가 배우는 유일한 반복 노출 지점.
- 광고 400px 규칙도 전신 일러스트에만. 배지는 광고 띠와 겹쳐도 시선 경쟁이 작다(추정 → 리서치 2 대상).
- 반증되면 대안: (a) 선반은 꽃 아이콘 유지 + 선반 머리에 1마리만(첫 선반), (b) home-shelves 광고를 씨앗 도서관 아래로 이동(광고는 꺼져 있지만 심사 중 구조 변경 주의 — OPERATING 6-1).

### 2-4. 에셋 파생
- `scripts/mascot-derive.mjs`(sharp 또는 cwebp): 원본 512² → 표시 1×·2× webp(q80), 출력 `public/art/m/<name>-<px>.webp`. 대상: mallang-idle·tori-idle·haessi-idle·bomi-idle(배지 40→80), haessi-think·haessi-guide(96→192, 72→144), bomi-countdown(32→64), hub-404-drifted-islet(360→720w, ≤40KB).
- 각 파일 ≤40KB를 테스트로 고정(`fs.statSync` 단위 테스트), 마젠타 프린지 육안 확인(캡처 1장).

### 2-5. 구현 단위
- `src/components/garden/Mascot.tsx`: `{who, pose, px, className}` → `<img alt="" aria-hidden width height loading="lazy" decoding="async" srcSet=1x,2x>`. 진입 1회 '퐁' 등장(transform 200ms), reduced-motion이면 없음. 무한 루프 없음.
- 문구 규칙: 마스코트 말풍선 없음(문구는 본문 텍스트), 죄책감·압박 표현 금지(lint 대신 리뷰 체크리스트).
- 테스트: Mascot 렌더(alt·크기·lazy), 파생 파일 크기 ≤40KB, DailyResultSheet 슬롯 테스트 갱신(빈 요소 → 보미 img 1개), GameBrowser 빈 상태 2종(문구·링크), not-found 정적 렌더(링크 3 + 인기 4). e2e: `/nope` → 404 정원 화면·검색 이동, 홈 390 선반 배지 4 표시·CLS.
- 측정 완료 기준: CLS 0(배지·About·시트), 홈 추가 전송 ≤ 40KB(배지 4×~4KB + About 1, lazy), axe 위반 0, 홈 내부 링크 감소 0, 404 링크 ≥ 7.

### 2-6. 유입·다음 행동·재방문 (연결 구조)
- 유입: 깨진 링크·옛 URL·오타 → 404(지금은 Next 기본 화면, 사이트 크롬도 없음 = 이탈).
- 다음 행동: 404·빈 상태마다 버튼 1 + 링크. 시트는 Next game(R5)과 카운트다운.
- 재방문: 보미 = '내일 호 배달' 고정 역할 → 카운트다운과 함께 반복 노출.

## 3. 사용자 관점 질문 (v1 답)
1. **처음 온 사람**: 404에 오면 지금은 흰 기본 화면 → v1은 정원 크롬 + "섬이 떠내려갔어요" + 버튼 3개로 3초 안에 다음 행동. 근거: 기본 404 확인(not-found.tsx 없음).
2. **왜 계속 하나**: 마스코트 자체는 재방문 이유가 아니다. 보미 카운트다운이 '내일 호'를 상기시키는 정도(효과 미측정, n<30이면 판정 보류).
3. **왜 못 하나**: 검색 0건일 때 지금은 문구 한 줄 → 해씨 + 카테고리 칩으로 막다른 길 제거.
4. **어떻게 쓰나**: 그림은 전부 장식(alt=""), 버튼은 44px, 모션 1회·reduced-motion 정지, 390에서 배지 40px이 선반 이름을 밀지 않는지 캡처 필요.
5. **왜 공유하나**: 공유 카드는 결과가 주인공(Wordle·NYT 패턴) — 마스코트 추가 안 함.
6. **우리 사이트에서 왜**: Poki·Coolmath에는 없는 '정원 지기' 세계관. CrazyGames가 10월 Ziggy로 같은 방향 — 차별점은 4마리가 카테고리·기능을 나눠 맡는다는 점(추정, 리서치 2에서 반증 시도).
7. **오너가 볼 때**: 예상 지적 — "배지가 작아 누군지 안 보인다", "404 그림 좋은데 왜 게임 페이지엔 없나". 대비: 배지 390 캡처 혹평, 게임 페이지는 R7·퀄리티팀 몫으로 명시.

## 4. 리서치 2(16시)에서 반증할 가정
- H1 얼굴 배지 4개가 한 목록에 있어도 '시끄럽다'고 느끼지 않는다(카테고리 아이콘 관행).
- H2 404·빈 상태 마스코트가 이탈을 줄인다(정량 근거 없음 — 계측으로만 판정).
- H3 512² → 2× 파생이 마젠타 프린지 없이 깨끗하다.
- H4 보미 32px가 카운트다운 옆에서 판독된다(390 캡처).
- H5 광고가 켜졌을 때 배지 400px 예외가 AdSense 정책·사용성에 문제없다.

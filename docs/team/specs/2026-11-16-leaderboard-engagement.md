# 큰 기능 스펙: 리더보드 참여 (화 11-17)
- **목표/가치**: 게임오버 직후 신기록을 한 번에 제출, 빈 주간 보드가 고장처럼 보이지 않게 함.
- **완료 조건**: ① 신기록 게임오버 오버레이에서 저장된 이름으로 1클릭 제출 ② 빈 주간 보드에 지난주·역대 최고 표시 ③ /leaderboards에서 빈 보드 접기 ④ 중복 제출 방지 유지, 테스트 추가.
- **계측**: `lb_submit`(11-16 반영), 오버레이 제출은 `lb_submit_overlay` 추가.
- **하지 않을 것**: 계정/로그인, 광고를 게임 화면에 넣기, 공유 URL 변경.
- **단계**: 1) 오버레이 제출 2) 빈 보드 대안 3) /leaderboards 정렬.

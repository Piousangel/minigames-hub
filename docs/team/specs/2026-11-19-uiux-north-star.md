# 상시 안건: 사이트 전체 UI·UX를 고품질·독창적으로 (오너 11-19, 허브·샌드랩 공통)

오너 원문 취지: "샌드랩, 미니게임 허브의 전체 UI·UX는 어떻게 하면 고품질 및 독창적으로 만들어낼 수 있는지 계속 고민해야 한다."
이 문서는 한 번 하고 끝나는 과제가 아니라 **모든 교대가 계속 지는 상시 안건**이다.

## 판단 기준 (모든 PR에 적용)
1. **고품질**: 390px 첫 화면 캡처에서 '지금 앱스토어 상위권 캐주얼 앱' 수준인가(혹평 리뷰 6.5+). 모션은 입력 80ms 안 반응, 보상 연출 ≤900ms, 이징 고정 토큰(opinion-designer.md 1-4).
2. **독창성**: 다른 포털(Poki·CrazyGames 등)에 그대로 놓아도 우리 것이라고 알아볼 수 있는가 — '노을 정원' 세계관, 젤리 스프링 UI, 하루가 정원이 되는 공유 등 시그니처를 강화하는 방향인가. 범용 템플릿 느낌(회색 카드·블러 그림자·시스템 폰트·이모지 아이콘 남발)은 감점.
3. **일관성**: 디자인 토큰(globals.css --garden-*), 44px 규격, 같은 결과 카드·버튼·HUD 언어.

## 운영
- **04시 기획·디자인 숙의 교대**: 매일 사이트 UI·UX 개선 후보 1개 이상을 리서치→기획→반증→독립 리뷰까지 문서화해 08시 개발에 넘긴다.
- **00시 QA 교대**: UI 회귀(깨짐·잘림·불일치) 점검을 포함한다.
- **주 1회(월) UI 혹평 라운드**: 홈·게임 페이지·리더보드·결과 화면 390px 캡처 → 디자이너·플레이어·비평가 서브에이전트 혹평(10점 척도) → 상위 3개 개선을 그 주 백로그 최상단에.
- **참고 레포·벤치마크**: docs/team/research/ 에 유지(첫 조사 11-19 진행 중). 분기마다 갱신.
- **디자인 부채 목록**: docs/team/design-debt.md 에 심각도·캡처·제안과 함께 쌓고, 교대가 하나씩 지운다.

## 0. 결론 먼저
1. **라이브 2단계 콜백이 약하다(실측·재현).** `c-meadow`는 1단계 해의 **60%**가 그대로 통과하고 1단계 추천 길도 통과한다. 같은 g-slide 땅에서 독꽃을 (105,186),(104,275)로 옮기면 통과 **24%**(재현 23.75%), 1단계 추천 길·대각선 직선이 독꽃에 닿고 tier1 게이트 통과(CB-3은 미측정). 단 g-slide는 막대 지형이고 v3에서 연습으로 빠지므로 이건 **라이브 임시 강화안(legacy 트랙)**이다. v3 2단계는 `v3-first-light` 위에서 같은 방법으로 다시 찾는다.
2. 하루 8판 = **막 3개**: I 들판(1~3) · II 쌍둥이 둑(4~6) · III 등불 능선(7~8). 막 안은 같은 땅 + 바뀌는 것 하나, 막 사이(3→4, 6→7)는 이음매(앞 막 둥지 자리 = 다음 막 출발 턱, 카메라 500ms, 건너뛰기).
3. 콜백 여부는 **게이트로 판정**한다(CB-1~5, 2장). Braid 기준: 같은 땅이라도 해법이 바뀌면 콜백, 같으면 재탕.
4. 실측·리뷰로 4개 판이 v2 그대로는 안 된다: **3**(계단 규칙 위반·c20 미달) **4**(낙서 69% = tier2 미달, 별 3 미확정) **5**(실측 D로 1선 건너뛰기가 이미 반증됨) **6**(v1 쿠션 사용 0%). 각각 재설계 방향과 측정 조건을 3장에 둔다. **미측정 판은 출시 금지**(v3 E장 원칙 그대로).
5. 08시 개발은 **풀을 바꾸지 않고**(일일은 매일 `SLIME_STAGES` 전체를 연다 — 바꾸면 오늘 기록·서버 제출이 깨진다) 정의·테스트·순수 함수만 넣는다(4장).

## 3. 단계별 상세

### 3-1. 2단계 Morning Meadow
- **legacy 강화안(실측 PASS)** — id `c-meadow-2`(id 불변 규칙: c-meadow를 고치지 않고 새 id). `{ ...GATE_STAGES[0], id: 'c-meadow-2', tier: 1, spikes: [{x:105,y:186},{x:104,y:275}], acorns: [{x:70,y:144},{x:70,y:298},{x:207,y:442}], ink: 520 }`, 추천 길 `[{x:30,y:316},{x:129,y:410},{x:210,y:468}]`(잉크 236, 별 3).
  실측(runs 400): CB-1 24%, 낙서 8%, c12 1회차 94%·3시도 100%, c20 69%, 직선 4%, 힌트 σ12 0.98, 물리 9조합 변동 2%p. CB-2: g-slide 추천 길 spiked, 대각선 직선 spiked. 주의: c-meadow 추천 길은 여기서도 별 3 도착, c-meadow 해의 84%가 통과(엔지니어 재현) — 오늘 c-meadow로 연습한 사람에겐 쉬운 판이다.
- **v3판**: `v3-first-light`(PR-8)가 확정되면 같은 탐색(`slime-exp/a.ts`, 독꽃 2~3개 후보 1,500개 → CB-1 ≤35%·CB-2·tier1)을 그 땅에 다시 돌린다.
- 시각: 독꽃은 보드 위쪽에서 늘어진 **덩굴(v3 F-2 소품 시트 ③, 윤곽 ≤2px·알파 70%)** 끝에 핀 꽃. 꽃 머리 중심 = 판정 원(r26) 중심. 덩굴은 충돌 없음.
- 전환(1→2): 4장 타임라인 U1. 변화(꽃 피기)가 보드 위쪽 절반이라 **타이틀 카드는 y=70%**.

### 3-2. 3단계 Stone Steps (재설계, 미측정)
- 3단 후보(실측, `slime-r2-measure.md` B): CB-1 18%, 낙서 19%, c12 75%, **c20 20%(<30%)**, 9조합 15%p(경계). 그리고 v3 규칙 위반 3개: 단 높이 42.5px(<60), 둥글림 ≈10px(A-1 14번은 직각 `corner:true` + 장식 ≤3px), 윗단 평면 17px(둥지 규칙 ≥38px 또는 폭 ≥80 그릇 미달). → **폐기, 아래 기본값으로 다시 잰다.**
- 새 기본값: 계단 **2단**, 단 높이 ≥60·단 길이 ≥60, 모서리 `corner:true` 직각(장식 둥글림 ≤3px), 꽃은 윗단의 **폭 ≥80 둥근 그릇** 안, 뒤는 둥근 뒷바위(막대 아님), 독꽃은 2단계와 같음. 잉크·별은 허용 파라미터(CB-1 ≤20%를 맞추는 데 쓴다).
- 합격: tier2 v4.1 전부(c20 ≥30% 포함) + CB-1 ≤20% + 9조합 ≤15%p. 두 번 안에 안 되면 기준을 낮추지 않고 오너 결정 요청(3단계만 c20 예외 / 다른 콜백 변화).
- 전환(2→3): 계단 완성본을 오프스크린에 한 번 구운 뒤 +145px 아래에서 0으로 클립해 올림(500ms, −4px 오버슈트), 옛 바닥 200ms 페이드, 흙먼지 6개(크림, ink 2px 윤곽).

### 3-3. 4·5단계 Twin Hills → Two Banks
- 4 지형 실측(`slime-r2-measure.md` C): 1선 c12 90%·**낙서 69%·직선 77%** → v3 B-2 4단계 기준(tier2 낙서 ≤20%, 무작위 2선 ≤6%) **미달**. 숨 돌림 판이라도 낙서로 깨지면 안 된다. 재설계: 둥지를 오른쪽 언덕 **너머 오목 그릇**에 두어 직선·낙서가 언덕 꼭대기에서 넘어가게, 골짜기를 깊게.
- 별 3: (130,300)은 1선 0개지만 비공식 2선도 1개·σ8 0 → **PR-7 2선 솔버로 다시 찾는다.** 조건: 1선 별 3 해 0, 2선 별 3 강건 해 σ8 생존 ≥0.5. 방향: 둘째 선이 '받침대'가 되는 골짜기 위 중간 높이.
- 4 지형의 스폰 턱은 지금 렌더러에서 bbox 규칙으로 ridge가 되어 왼쪽에 폭 112px 기둥이 칠해지고 그 오른쪽 면은 충돌선이 없다(디자이너 지적) → **PR-1 `closeTo:'side'` 선행.**
- 5 = 4의 땅 + 골짜기 바닥 제거(강, 빠지면 `fell`) + 금지 기둥 x 175~245. **반증된 위험**: 실측 D에서 금지 범위를 건너편 둑 전체까지 넓혀도 짧은 1선(잉크 73~108)이 강을 건너뛰었다(해 1,498). 5의 금지는 기둥뿐이라 더 쉽다. → 건너편 둑 착지면을 **급경사 + 오목**하게 만들어 1선으로 날아온 말랑이가 튕겨 강으로 떨어지게(물리로 막기). CB-4(1선 제한 해 0)가 5 게이트의 첫 항목.
- 화면: 4 진입 때 컨트롤 줄 변화는 없다(시작 ▶은 1단계부터, 오너 결정). 4에서 바뀌는 건 선 핍이 1→2로 느는 것 하나. 5 진입은 강 차오름(600ms) → 손가락 시범은 1400ms부터 → 고스트 ✕는 시범 뒤.

### 3-4. 6단계 Jelly Hollow (막 II 3판째, 미측정)
- 5→6: 강물이 빠져 골짜기가 움푹한 골이 된다(면적 ≥25% 변화). 금지 구역은 없다(금지 구역은 하루 1판, 플레이어 리뷰). 5단계 2선 풀이는 둘째 선 자리(건너편 둑 착지)가 골 벽으로 바뀌어 죽는다.
- 실측 교훈(D): 선을 그을 수 있는 곳 어디서든 발사가 되고 쿠션은 반발 0.85라 에너지를 더하지 않는다 → '쿠션을 놓아두는' 설계는 필요성이 안 생긴다.
- **후보 A(우선) 젤리 잉크**: 이 판에서 그은 선 자체가 젤리(튕김)다. 플레이어가 각도로 튕김을 직접 만든다(플레이어 리뷰: "쿠션이 푸는 퍼즐"을 피함). 엔진: `Stage.bouncyLines?: true`면 선 선분에 `bouncy` 계수 적용(+5줄 안팎, 필드 없으면 골든 비트 동일). 필요성: 골 건너편 선반을 미끄러지는 선으로는 못 오르고 튕김으로만 닿는 높이·각도로 — **CB-4(같은 판을 일반 잉크로 풀면 해 0)**.
- 후보 B 젤리 바닥 + 처마: v2안. 처마(떠 있는 바위)는 PR-1 `closeTo:'under'` 선행, 플레이어 개입이 적다.
- 둘 다 측정 후 결정(`slime-exp/d.ts` 출발점). 둘 다 안 되면 6은 v3 원안(능선 홈 + 쿠션 벽, 새 땅)으로 되돌리고 막 II는 2판.

### 3-5. 7·8단계 Windy Ridge → Lantern Gate
- 7: 능선 + 협곡 + 구름 발판 2개(v3 B-2, 구름은 `closeTo:'under'` 선행) + 협곡 위 바람띠(엔진 `zones` ~12줄). 협곡 앞 턱에 **꺼진 스위치**(8과 같은 외형, 회색, 48×16 이상 — 보드 0.85배 축소에서 40×14는 안 보임). 7에서는 밟아도 아무 일 없다(의미 없는 물체지만 거짓 신호는 아님: 처음부터 '꺼진 것'으로 보임).

## 6. 일일 신선도 (오너 승인안 그대로)

### Q1 [중] 말랑 미끄럼길: 실제 폰 가시 영역에서 꽃(도착점)이 첫 화면 밖
- 재현: 390×664(iOS Safari 툴바 포함 가시 높이)로 `/slime-slide` 열기 → 캔버스 top 352px, 높이 488px → 하단 840px. 꽃·도착 섬이 176px 아래(스크롤해야 보임). 390×844에서도 22px 잘림(꽃 받침 섬이 화면 끝에 걸림).
- 원인: `SlimeProto.tsx` 보드 크기 식이 위쪽 크롬을 **250px로 가정**(`window.innerHeight - 250`)하고 폭 하한 340px — 실제 보드 위 크롬은 352px(헤더 56 + 2행 내비 46 + 제목·탭·여정 막대·잉크 줄). **R2(#179) 헤더가 모바일 크롬을 ~44→102px로 키워 악화**(2행 내비는 sticky 아님, 의도된 설계).
- 영향: 첫 판에서 목표가 안 보여 '어디로 그리지?' — 그리다 스크롤 사고 방지 목적(코드 주석)과도 충돌.
- 제안(디자인 결정 필요, QA가 임의로 안 고침): ① 보드 top을 실측(`getBoundingClientRect().top + scrollY`)해 높이 상한 계산 ② 게임 페이지에서는 2행 내비를 숨기거나 1행에 합침(R 계획 담당) ③ 첫 진입 시 보드로 `scrollIntoView({block:'end'})`. 오너 '폭 꽉 채우기'와 상충하므로 ①+③ 조합 권장.

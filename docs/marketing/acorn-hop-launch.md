## 이미지가 붙는 다채로운 게시 (11-17 추가, 오너 요청: "이미지 캡쳐도 올리고, 다채롭게")
게시 스크립트가 이제 **이미지와 캐러셀**을 지원한다(`scripts/post-social.mjs`). Bluesky는 이미지 최대 4장(링크 카드 대신), Threads는 1장이면 이미지 게시, 2장 이상이면 **캐러셀**. 파일이 없거나 형식·용량(900KB)이 맞지 않으면 게시하지 않고 `skipped-image-*`로 기록한다.

큐 예시:
```json
{ "channel": "threads", "text": "…", "url": "https://quickminigames.site/acorn-hop",
  "images": [ { "path": "docs/marketing/images/acorn-hop/cover.jpg", "alt": "Acorn Hop 키아트: 도토리를 쏘며 솟아오르는 우주 다람쥐 토리" },
              { "path": "docs/marketing/images/acorn-hop/play.jpg", "alt": "플레이 화면" } ] }
```
- 이미지는 **같은 PR에서 main에 머지**돼야 Threads가 공개 URL로 읽을 수 있다(`raw.githubusercontent.com`). 큐 파일과 이미지를 한 PR에 넣는다.
- 새 이미지는 Playwright로 실사이트를 2배 줌으로 캡처하거나(`documentElement.style.zoom=2`, 뷰포트 780 폭) Gemini 파이프라인(docs/team/GEMINI.md)으로 만든다. 글자는 이미지에 넣지 말고 본문에 쓴다.

## 전문 리뷰 반영 규칙 (11-17, 카피·이미지 전문가 + Threads API·스크립트 엔지니어)
**말투(오너 지시):** Threads는 친구에게 말하듯 **일상 반말체**("오늘 내가 만든 거야~ 스친들 한 판만 해봐줘~"). 광고체("나왔어요", "지금 바로 즐겨보세요") 금지. 단 `~`는 글당 2번 이하, 해시태그 1개, 이모지 1개, **같은 문장 구조를 반복하지 않는다**(매번 템플릿이면 스팸으로 읽힌다). 부탁은 "한 판만 해봐줘"처럼 행동 하나로.

**이미지 규격:** 캐러셀은 **전부 같은 비율(4:5, 예: 1080x1350)** 로 통일한다. 첫 장 비율이 전체를 정하고 섞으면 잘린다. 2:3 캡처는 자르지 말고 남색 여백으로 감싸 4:5로 만든다. 플레이 캡처는 어둡고 캐릭터가 작아 단독 썸네일로 약하니 캐릭터가 크게 보이는 이미지를 앞에 둔다. 추천 조합: `meet-tori.jpg` → `howto.jpg` → `result.jpg`(전부 4:5). `cover.jpg`(16:9)·`play.jpg`(2:3)는 다른 채널·링크 카드용.

**사실 확인:** 근거 없는 주장·개인 기록(예: "나는 58m")은 쓰지 않는다(실제 본인이 달성한 기록만). "설치 없이"는 사이트 문구("No download, no sign-up")로 확인됨. "모바일 지원" 같은 표현은 직접 한 판 해 본 뒤에만.

**운영:**
- 개인 계정에서 첫 글 이후 며칠은 자동 홍보를 **주 2~3회 이하**로 줄이고, 일상·개발 이야기를 섞는다.
- 한국 유저 반응이 좋은 **평일 저녁 8~10시 또는 점심 12시대**에 올린다. 올린 뒤 30분은 댓글에 답한다.
- 올린 뒤 permalink를 열어 캐러셀 두 번째·세 번째 장이 잘리지 않았는지, `?ref=threads` 링크가 200으로 열리는지 확인한다.
- 프로필(사진·소개)이 비어 있으면 첫 글의 신뢰가 깎인다(오너 계정 설정, 팀이 대신 못 함).

**게시 스크립트 안전장치(11-17 강화):** Threads 컨테이너 `FINISHED` 폴링, 항목마다 원장 즉시 저장, 게시 응답 유실은 `error-publish-unknown`으로 기록하고 자동 재시도하지 않음(중복 방지, 사람이 확인), 이미지 경로는 `docs/marketing/images/` 아래로 제한, raw URL은 커밋 SHA 기준. `error-publish-unknown`이 원장에 보이면 **오너에게 메일로 알리고** permalink를 직접 확인한다.
